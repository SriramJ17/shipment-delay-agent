# Demo scenarios

- Normal: no weather-related ETA adjustment.
- Severe transit: one-day illustrative adjustment.
- Recovery: reassess using current remaining transit time; do not blindly restore the original ETA.
- Extreme transit: two-day illustrative adjustment.
- Judge unavailable: fail closed; do not permit approval.
- Human rejection: retain the approved ETA and record the rejection.

The configured scenario duration is one minute. Use the immediate assessment button to avoid waiting during a live presentation.
